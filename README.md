## 📌 প্রজেক্ট পরিচিতি (Project Overview)

**Dino Game (2.8" TFT Edition)** হলো বিখ্যাত Chrome অফলাইন **T-Rex Dino Game**-এর একটি স্ট্যান্ডএলোন হার্ডওয়্যার পোর্ট, যা **ESP32-S3**-এ **2.8" ST7789 TFT ডিসপ্লে** ও **XPT2046 রেজিস্টিভ টাচস্ক্রিন** দিয়ে চলে। মূল গেম ইঞ্জিন [T-rex-duino](https://github.com/AlexIII/t-rex-duino) (মূলত ছোট 1.3" SH1106 OLED-এর জন্য তৈরি) অপরিবর্তিত রেখে, একটি কাস্টম **ST7789 Display Adapter** লেখা হয়েছে যা ছোট মনোক্রোম ১২৮×৬৪ গেম ক্যানভাসকে বড় ২৪০×৩২০ TFT প্যানেলে PSRAM ফ্রেম-বাফারের মাধ্যমে স্কেল-আপ করে ক্রিস্প ভাবে দেখায়।

গেমটি জাম্প করতে **স্ক্রিনের যেকোনো জায়গায় টাচ** অথবা একটি **ফিজিক্যাল পুশ-বাটন** — দুটোই সাপোর্ট করে, এবং একটি সম্পূর্ণ **অন-স্ক্রিন সেটিংস মেনু** (৪-ওয়ে রোটেশন, টাচ ক্যালিব্রেশন, কালার ইনভার্ট) রয়েছে যা ESP32-এর অনবোর্ড **BOOT বাটন** দিয়ে যেকোনো সময় খোলা যায় এবং NVS-এ (ফ্ল্যাশ) সেভ থাকে।

## ✨ প্রধান ফিচারসমূহ (Key Features)

- 🖥️ **Native-Resolution Sharp Rendering:** আসল ১২৮×৬৪ পিক্সেল গেম ক্যানভাসকে ব্লক-স্কেলিং দিয়ে পুরো ২৪০×৩২০ প্যানেলে স্ট্রেচ করা হয় (RGB565 PSRAM ফ্রেম-বাফার ব্যবহার করে), সাথে টেক্সট-বেজড নেটিভ স্প্ল্যাশ স্ক্রিনও (আপস্কেলড বিটম্যাপ নয়) আলাদাভাবে ক্রিস্পভাবে আঁকা হয়।
- 🔄 **ফুল ৪-ওয়ে স্ক্রিন রোটেশন:** ০°/৯০°/১৮০°/২৭০° — পোর্ট্রেট ও ল্যান্ডস্কেপ, দুই অরিয়েন্টেশনেই খেলা যায়; একই ফ্রেম-বাফার অ্যালোকেশন সব রোটেশনে রিইউজ হয়।
- 👆 **ডুয়াল জাম্প ইনপুট:** স্ক্রিনের যেকোনো জায়গায় ট্যাপ **অথবা** ফিজিক্যাল পুশ-বাটন — যেকোনো একটি দিয়ে ডাইনো জাম্প করে।
- ⚙️ **ইন-গেম সেটিংস মেনু (BOOT বাটনে):** স্প্ল্যাশ স্ক্রিন, মিড-গেম বা গেম-ওভার — যেকোনো অবস্থা থেকে ESP32-S3-এর অনবোর্ড BOOT বাটন চেপে সেটিংস মেনু খোলা যায়।
  - **ROTATION:** ৪টি রোটেশন অপশন থেকে লাইভ প্রিভিউসহ সিলেক্ট করা।
  - **TOUCH CONFIG:** Invert Y, Invert X, Swap Axis — প্রতিটি রোটেশনের জন্য আলাদা আলাদা টাচ ম্যাপিং ফাইন-টিউন করার অপশন, সাথে এক-ক্লিকে Reset Defaults।
  - **CALIBRATE/VERIFY:** ৮-পয়েন্ট (Up/Down/Left/Right + ৪ কোণা) টাচ অ্যাকুরেসি টেস্ট স্ক্রিন।
  - **INVERT COLORS:** পুরো প্যানেলের হার্ডওয়্যার কালার ইনভার্ট টগল (লাইভ প্রিভিউসহ)।
  - **SAVE:** সব সেটিংস ESP32-এর NVS ফ্ল্যাশে পার্মানেন্টলি সেভ হয় — পাওয়ার সাইকেলের পরেও থেকে যায়।
- 🌗 **ডে/নাইট মোড:** নির্দিষ্ট স্কোরের পর গেম নিজে থেকেই স্ক্রিন কালার ইনভার্ট করে ডে থেকে নাইট মুডে পরিবর্তন করে (মূল Chrome Dino গেমের মতোই)।
- ❤️ **লাইভস সিস্টেম:** ৩টি লাইভ নিয়ে শুরু, পথে হার্ট আইটেম কুড়িয়ে ৫টি পর্যন্ত লাইভ বাড়ানো যায়, প্রতিটি হিট/হার্টের জন্য আলাদা বাজার সাউন্ড।
- 🔊 **প্রোগ্রামেটিক বাজার সাউন্ড এফেক্ট:** জাম্প, হিট, গেম-ওভার, হার্ট পিকআপ ও মেনু-ব্যাক — প্রতিটির জন্য আলাদা মাল্টি-নোট বিপ মেলোডি (নন-ব্লকিং `tone()` ভিত্তিক)।
- 🎮 **প্রোগ্রেসিভ ডিফিকাল্টি:** স্কোর বাড়ার সাথে সাথে টার্গেট FPS/গেম স্পিড ধীরে ধীরে বাড়তে থাকে (২৩ থেকে ৪৮ FPS পর্যন্ত)।
- 🖐️ **মাল্টি-ক্লিক ও লং-প্রেস ডিটেকশন:** সিঙ্গেল/ডাবল/ট্রিপল/কোয়াড ক্লিক ও লং-প্রেস — ডিবাউন্সড জেসচার ডিটেকশন ইঞ্জিন সহ (গেম-ওভার স্ক্রিনে রিস্টার্ট কন্ট্রোলের জন্য ব্যবহৃত)।
- 💾 **অপরিবর্তিত মূল গেম ইঞ্জিন:** `TRexCore.h` (AlexIII-এর মূল T-rex-duino লজিক) কোনো পরিবর্তন ছাড়াই ব্যবহার করা হয়েছে — শুধু ডিসপ্লে অ্যাডাপ্টার লেয়ার নতুন করে লেখা হয়েছে।

## 🔌 পিন টু পিন কানেকশন (Detailed Pinout Diagram)

### 🖥️ ১. 2.8" ST7789 TFT Display → ESP32-S3 Connection
| TFT Pin | ESP32-S3 GPIO Pin | কাজ |
| :--- | :--- | :--- |
| **CS** | **GPIO 10** | SPI Chip Select |
| **RST** | **GPIO 8** | Reset Pin |
| **DC** | **GPIO 9** | Data/Command |
| **SCK** | **GPIO 13** | SPI Clock |
| **MOSI** | **GPIO 11** | SPI Data In |
| **MISO** | **GPIO 12** | SPI Data Out |
| **LED (Backlight)** | **3.3V** | (সরাসরি 3.3V-এ, GPIO 5 না ব্যবহার করলে) |
| **VCC** | **3.3V** | পাওয়ার সাপ্লাই |
| **GND** | **GND** | গ্রাউন্ড |

### 👆 ২. XPT2046 Touch Controller → ESP32-S3 Connection
| Touch Pin | ESP32-S3 GPIO Pin | কাজ |
| :--- | :--- | :--- |
| **T_CS** | **GPIO 7** | Touch Chip Select |
| **T_CLK** | **GPIO 13** | SPI Clock (TFT-এর সাথে শেয়ার্ড) |
| **T_DIN (MOSI)** | **GPIO 11** | SPI Data In (TFT-এর সাথে শেয়ার্ড) |
| **T_DO (MISO)** | **GPIO 12** | SPI Data Out (TFT-এর সাথে শেয়ার্ড) |
| **T_IRQ** | **GPIO 6** | Touch Interrupt (ঐচ্ছিক) |

> 🔗 **নোট:** টাচ ও TFT একই SPI বাসের CLK/MOSI/MISO শেয়ার করে — এটা স্বাভাবিক, প্রতিটি ডিভাইস নিজের CS (Chip Select) পিন দিয়ে আলাদাভাবে সিলেক্ট হয় (TFT_CS=10, TOUCH_CS=7)।

### 🔘 ৩. JUMP পুশ-বাটন → ESP32-S3 Connection
| বাটন লেগ | ESP32-S3 GPIO Pin | কাজ |
| :--- | :--- | :--- |
| **এক লেগ** | **3.3V** | পাওয়ার |
| **ডায়াগোনাল লেগ** | **GPIO 4** (`JUMP_BUTTON_PIN`) | জাম্প ইনপুট (INPUT_PULLDOWN, Pressed = HIGH) |

### 🔘 ৪. Onboard BOOT Button (Settings Menu)
| ফাংশন | ESP32-S3 GPIO Pin | কাজ |
| :--- | :--- | :--- |
| **Settings Menu Open** | **GPIO 0** (Onboard) | যেকোনো সময় সেটিংস মেনু খোলে (কোনো ওয়্যারিং লাগে না) |

## ⚙️ সিস্টেম কীভাবে কাজ করে (How It Works)

1. বুটআপে `settings_load()` দিয়ে NVS থেকে সংরক্ষিত রোটেশন ও টাচ ক্যালিব্রেশন সেটিংস লোড হয় এবং `settings_apply()` দিয়ে সাথে সাথে প্রয়োগ করা হয়।
2. মূল গেম ইঞ্জিন (`TRexCore.h`) তার আসল ১২৮×৬৪ মনোক্রোম বাইট-বাফার (SH1106-স্টাইল, প্রতি বাইটে ৮টি উল্লম্ব পিক্সেল) `lcd.fillScreen(buffer, size)`-এ পাঠায়।
3. **ST7789DinoDisplay Adapter** প্রতিটি বাইট থেকে পিক্সেল আনপ্যাক করে, বর্তমান স্ক্রিন সাইজ অনুযায়ী ব্লক-স্কেল করে RGB565 PSRAM ফ্রেম-বাফারে লেখে; পুরো লজিক্যাল ফ্রেম কমপ্লিট হলে (কার্সর র‍্যাপ করলে) একটি বাল্ক SPI ট্রান্সঅ্যাকশনে পুরো বাফার প্যানেলে পুশ হয় — ফলে স্মুথ, ফ্লিকার-ফ্রি রেন্ডারিং হয়।
4. টাচ ইনপুট **XPT2046** থেকে raw ADC কোঅর্ডিনেট হিসেবে আসে, যা `getMappedTouch()` রোটেশন + ইউজারের invertX/invertY/swapXY সেটিংস অনুযায়ী প্রকৃত স্ক্রিন কোঅর্ডিনেটে ম্যাপ করে।
5. যেকোনো সময় **BOOT বাটন** চাপলে (ডিবাউন্সড এজ-ডিটেকশন) সেটিংস মেনু ব্লকিং-লুপে ওপেন হয়ে যায় — মেনু থেকে বেরোলে গেম ঠিক যেখানে ছিল সেখান থেকেই আবার চলতে থাকে।
6. গেমপ্লেতে স্কোর বাড়ার সাথে সাথে টার্গেট FPS বাড়ে, নির্দিষ্ট ইন্টারভালে ডে/নাইট মোড টগল হয়, এবং ক্যাকটাস/টেরোড্যাকটিলের সাথে কলিশন হলে লাইভ কমে যায় বা গেম ওভার হয়।

```
 ┗ 📜 TRexCore.h                → মূল T-rex-duino গেম ইঞ্জিন (AlexIII, অপরিবর্তিত)
```

## ⚙️ আর্ডুইনো আইডিই আপলোড সেটআপ (Arduino IDE Setup)

1. **Board:** `ESP32S3 Dev Module`
2. **PSRAM:** `OPI PSRAM` / `Enabled` (ফ্রেম-বাফার PSRAM-এ অ্যালোকেট হয় — এই অপশন সঠিকভাবে সেট না করলে গেম স্লো হবে বা ক্র্যাশ করবে)
3. **Upload Speed:** `921600` (বা স্ট্যাবল স্পিড)
4. **Partition Scheme:** `Default`
5. উপরে উল্লেখিত সবগুলো লাইব্রেরি (`Adafruit GFX`, `Adafruit ST7735/ST7789`, `XPT2046_Touchscreen`) ইনস্টল করুন।
6. `Dino_game_TFT28.ino`, `Settings.h`, `TRexCore.h`, `ST7789_DinoAdapter.h`, `t-rex-duino-TFT.h` — সবগুলো ফাইল একই ফোল্ডারে রাখুন।
7. সঠিক **COM Port** সিলেক্ট করে `Upload` চাপুন।
8. আপলোডের পর প্রথমবার স্প্ল্যাশ স্ক্রিনে BOOT বাটন চেপে **CALIBRATE/VERIFY** মেনুতে গিয়ে আপনার প্যানেলের টাচ ক্যালিব্রেশন চেক করে নিন, প্রয়োজনে TOUCH CONFIG থেকে ঠিক করে SAVE করুন।
